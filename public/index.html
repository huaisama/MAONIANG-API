How it works

三步，一个循环

它不只是个 mock —— 响应体永远由人现场写，所以能返回任何东西，包括你想让客户端看到的那句话。

调用方发请求

SDK / curl / 任何 HTTP 客户端，指向这个站点，带 key 就行。请求体、header、路径全部记录。

请求进入队列

连接保持挂起，控制台里出现一条待回复卡片，带倒计时、来源 IP 和原始报文。

人写，立刻返回

你填状态码、Content-Type、响应体，Ctrl+Enter 发送。挂起的连接当场拿到你写的东西。
